## How to Run

Install the required libraries:

pip install -r requirements.txt

Train the model:

python handwritten_recognition.py

Run the application:

streamlit run app.py
## Application

The Streamlit application allows the user to upload a handwritten digit image and get the predicted digit with a confidence score.

## Model Evaluation

The model is evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix
